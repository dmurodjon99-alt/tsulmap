# TSUL Campus — интерактивный портал кампусов ТГЮУ

Мультиязычный (UZ / RU / EN) справочник подразделений Ташкентского государственного
юридического университета: факультеты, кафедры, службы, центры и аудитории.

Стек: **React 18 + Vite + Tailwind CSS 3 + react-i18next + react-router**.
Оформление — Glassmorphism поверх фонового изображения кампуса, палитра tsul.uz
(глубокий синий + сдержанный золотой акцент).

---

## Запуск

Требуется Node.js 18+ (проверено на **Node v24.18.0 / npm 11.16.0**).

```bash
npm install
```

```bash
npm run dev
```

Продакшн-сборка:

```bash
npm run build
```

> **Если PowerShell пишет `npm : The term 'npm' is not recognized`** — Node установлен,
> но его каталог не прописан в PATH текущей сессии. Разово:
>
> ```bash
> $env:Path = "C:\Program Files\nodejs;$env:Path"
> ```
>
> Чтобы починить навсегда — добавьте `C:\Program Files\nodejs` в переменную среды
> PATH пользователя (Параметры → Система → Дополнительные параметры системы →
> Переменные среды).

> Фоновое изображение кампуса положите в `public/campus.jpg` — оно подхватится
> автоматически через CSS-переменную `--campus-bg`. Пока файла нет, работает
> градиентный фолбэк, интерфейс выглядит корректно.

## Архитектура мультиязычности

Переводы разделены на два независимых пласта — это главное архитектурное решение
проекта:

**1. UI-строки** → `src/i18n/locales/*.json`, неймспейсы `common / nav / search /
building / unit`. Обычный `useTranslation()`.

**2. Контент** (подразделения, ФИО, часы приёма) → `src/data/**`.
Контент **не дублируется по языкам**: каждое поле — объект `{ ru, en, uz }`,
который разрешается хелпером `pick()` в момент рендера.

```js
// данные
name: L('Юридическая клиника', 'Legal Clinic', 'Yuridik klinika')
//  → { ru: '…', en: '…', uz: '…' }

// компонент — один на все три языка, без ветвлений
const { L, Lx } = useL10n();
<h2>{L(unit.name)}</h2>
```

Цепочка фолбэков — `uz → ru → en`. `Lx()` дополнительно возвращает
`{ value, lang, isFallback }`, и компонент `<TranslationNotice/>` честно
показывает бейдж «перевод готовится», если текст отрисован не на выбранном языке.

Добавить язык = добавить запись в `SUPPORTED_LANGUAGES`, файл локали и ключ в
объектах контента. Компоненты менять не нужно.

### ⚠️ О состоянии узбекских переводов

В присланных материалах **узбекского текста почти нет**:

| Файл | Что внутри фактически |
|---|---|
| `3 uz.txt` | настоящий узбекский текст (здание №3) ✅ |
| `1 uz.txt`, `2 uz.txt` | русский текст факультета бизнес-права (дубликат `4 ru.txt`) |
| `4 uz.txt` | дубликат `3 uz.txt` |

Поэтому в проекте:

* здание №3 заполнено на всех трёх языках полностью;
* для остальных зданий на узбекский переведены **названия подразделений,
  краткие описания, адреса, категории и весь UI**;
* длинные описательные блоки временно отдаются по фолбэку с пометкой
  «перевод готовится»;
* ФИО сотрудников в узбекской локали подставляются латиницей из английской
  версии (`withUzbekNameFallback` в `src/data/index.js`) — это корректнее, чем
  показывать кириллицу.

Чтобы дозаполнить узбекский, достаточно добавить третий аргумент в `L(...)` —
код и разметка не меняются.

## Поиск

`src/data/index.js` строит индекс при загрузке приложения. В индексе три типа
записей: **подразделения**, **аудитории**, **сотрудники**. Поле `haystack`
содержит склейку **всех трёх языков**, поэтому:

* «Moot Court» находится в русской версии интерфейса;
* «Имомов» — в английской;
* «401» ведёт сразу к экзаменационной аудитории 4-го корпуса, «хирагана» — к Японскому центру.

Ранжирование: точное совпадение → начало строки → начало слова → вхождение;
короткие записи получают бонус, тип влияет на порядок групп.
Горячая клавиша `/` — фокус на поиске, `↑`/`↓`/`Enter` — навигация по выдаче.

## Публикация

### Уже опубликовано: Claude Artifacts

Сборка `npm run build:artifact` кладёт всё приложение в один самодостаточный
`.html` (JS, CSS, логотипы и видео — base64, 13,5 МБ), а
`node scripts/make-artifact-page.mjs` готовит из него страницу для площадки.
В этом режиме роутер переключается на HashRouter, т.к. серверного fallback нет.

```bash
npm run build:artifact && node scripts/make-artifact-page.mjs
```

Страница приватная: ссылка работает только у владельца, пока он не откроет
доступ через меню share.

### Публичный адрес: любой бесплатный статик-хостинг

Обычная сборка `npm run build` → каталог `dist/`. Конфиги уже в репозитории:

| Хостинг | Что нужно | Файл в проекте |
|---|---|---|
| **Netlify** | `netlify deploy --prod` или перетащить `dist/` на app.netlify.com/drop | `netlify.toml`, `public/_redirects` |
| **Vercel** | `vercel --prod` | `vercel.json` |
| **Cloudflare Pages** | build `npm run build`, output `dist` | те же настройки, отдельный файл не нужен |
| **GitHub Pages** | запушить в `main`, включить Settings → Pages → Source: GitHub Actions | `.github/workflows/deploy-pages.yml` |

Во всех вариантах прописан SPA-fallback на `index.html` — без него прямые
ссылки вроде `/building/building-1?unit=b1-legal-clinic` отдавали бы 404.
Для GitHub Pages workflow дополнительно копирует `index.html` в `404.html`.

> Для аккаунта на любом из хостингов нужна ваша авторизация — эту часть
> выполняете вы; сборка и конфигурация уже готовы.

## Медиа: видео-заставка и логотип

`src/media/assets.js` — единственная точка импорта медиа; Vite сам хеширует
файлы и подставляет правильные URL в проде.

* **Видео** `DJI_0013_.mp4` — заставка первого экрана до блока «Учебные здания».
  Компонент `HeroVideo` растягивает его на всю ширину окна (`w-screen`, поэтому
  у `<body>` стоит `overflow-x: clip` — именно `clip`, а не `hidden`, иначе
  сломается `position: sticky` у шапки), уводит под шапку отрицательным сдвигом
  и гасит синим градиентом, который внизу переходит в цвет страницы.
  При `prefers-reduced-motion` автозапуска нет — остаётся статичный кадр.
* **Логотип** — три языковые версии (`logo_uz/ru/en.png`), переключаются вместе
  с языком интерфейса. Эмблема тёмно-синяя на прозрачном фоне, поэтому на тёмной
  теме она ставится на светлую круглую подложку: фирменные цвета сохраняются
  (инверсия их бы исказила).

## Адаптивность и доступность

Mobile-first: одноколоночная сетка → 2 колонки (`sm`) → 3–4 (`lg`/`xl`).
Drawer подразделения — полноэкранная панель на телефоне и боковая на десктопе.
Есть skip-link, `aria-*` у интерактивных элементов, фокус-кольца, поддержка
клавиатуры в поиске, а также `prefers-reduced-motion` (видео-заставка не запускается автоматически).
